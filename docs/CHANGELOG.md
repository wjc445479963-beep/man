# 变更记录

## 0.3.0 — 2026-09-25

- 重做陪伴主页：以人物和面对面对话为核心，手机对话期间保留人物在视野内。
- 新增两张同构图表情帧，WebGL 局部呼吸、眨眼、微笑、轻微头部与手部回应；离页释放资源，隐藏页面暂停，减少动态效果和 GPU 不可用时降级。
- 热区改为立绘自身坐标，随尺寸、近景与裁切同步，增加键盘替代入口。
- 增加四段数据化分支相处、逐字对白、回看、心情记忆、相处手记、每日首次奖励与可选一分钟陪伴/合成雨声。
- 保留旧存档；待发送短信存档，所有历史短信可查看，修复同一短信不同选项可重复领奖的问题。
- 修复剧情选择回应不可见、重玩第一句即退出的问题；保留一次性结算。
- 修复手机底部导航遮挡剧情继续按钮，校正剧情解锁门槛文案。
- 修复缓存脚本数字版本误替换 HTML 属性的问题，扩展到 data 模块与全部图片。
- 增加无外部依赖的交互回归检查，并完成桌面/手机浏览器试玩。
