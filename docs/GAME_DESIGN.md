# 游戏设计概要

## 产品定位

《雾港来信》是原创的手机陪伴与剧情互动游戏原型。玩家每天用几分钟问候、回复或调查，即可看到关系与故事发生细微变化。体验围绕「角色一直存在于我的手机里」展开，不依赖高频操作或玩家社交。

## 当前阶段

当前只做一名男主的完整纵向切片：主页陪伴 → 点击角色反馈 → 对话和好感 → 主动消息与回复 → 解锁调查场景 → 剧情结算 → 收到后续消息。第一版重点是验证这一循环，暂不开发抽卡、战斗、多人或在线服务。

## 玩法循环

1. 打开主页，查看角色当下状态与通讯。
2. 点触发梢、衣领或手部，进入对应的短对话。玩家回应后，人物表情和对白继续变化；完成相处才记录记忆和好感。
3. 在通讯中选择回复。每种回复带有独立好感值和角色回应。
4. 好感达到 10 后进入「潮汐档案」场景。过程包含叙事、玩家决定、明确的角色回应与结尾。
5. 场景结束后解锁条件对话、结局消息和后续约定，状态保存在本机。

## 内容原则

- 完全原创角色、设定、剧情、视觉资产和台词，不复用其他游戏的人物或美术。
- 当前角色资料为工作设定，后续逐轮完善身份、欲望、原则、弱点、秘密和成长线。
- 角色不会只有强势一面；行为尽量通过选择、细节和相处变化呈现。
- 用户可以随时退出故事，进度本地保留；不强制长时间在线、组队或重复跑图。

## 原型体验说明

浏览器本地存档按角色 ID 隔离。初次打开时收到主动短信。相处奖励：聊今天 +4、理头发 +3、牵手 +3、整理衣领 +2、一分钟陪伴 +2；每个项目按本机日期每天只在首次完成时奖励。重复相处仍可体验，但不鼓励连点刷数值。剧情门槛为 10 点好感，首次完成 +12 并生成新消息。

「聊今天」选择可留下疲惫、开心、想见面等心情，以及安静陪伴偏好。下次问候会参考记忆。完整结束才保存这些选择；随时可以退出，不惩罚玩家。相处记录展示最近 30 段；每日奖励记录保留最近 120 项。页面关闭期间没有后台推送，待发短信会在网页再次打开时送达。

舞台定位为动态立绘：局部形变和表情帧负责呼吸、眨眼与细微回应。牵手、整理头发的完整动作仍以文字叙述配合轻微画面反馈呈现，尚未有全身骨骼动作。
