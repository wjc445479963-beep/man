# 雾港来信

一款以碎片化陪伴、互动和剧情为核心的原创恋爱互动游戏原型。项目使用原生 HTML、CSS 与 JavaScript 模块，无需安装工具链即可运行；当前用原创矢量角色展示验证完整玩法链路，并为后续接入实时 3D 角色预留边界。

## 技术选型

第一阶段采用 **Web（原生 ES Modules）+ SVG/CSS**，不先引入大型游戏引擎：

- 开发速度与 AI 协作：标准 Web 技术、模块边界清楚，修改和审阅成本低；当前无第三方运行时依赖。
- Windows 与移动端：直接在桌面浏览器运行，布局适配手机尺寸；未来可以按需要封装为 PWA 或移动端容器。
- UI 和 2D → 3D：先用矢量角色、CSS 动效和数据驱动视图验证交互。展示层以 CharacterStage 接口隔离；后续可用 Three.js 场景替换 SVG 展示，而不重写关系、对话和剧情状态。
- GitHub 协作：静态文件可直接预览与审查，不需要大型二进制资源或特定编辑器。

Godot 4 是后续需要场景编辑器、骨骼动画、原生打包或大量实时 3D 内容时的候选方案；在当前以 UI 和陪伴链路验证为主的阶段，直接引擎化会增加启动成本。本选型并不把最终引擎永久锁定。

## 运行

在仓库目录启动一个本地静态文件服务器，然后用浏览器打开本机地址。Python 环境可运行 python -m http.server 8000，访问 http://localhost:8000。也可用 VS Code Live Server。无需 npm install。

## 当前可玩内容

- 首页角色陪伴页：待机状态、表情变化、身体区域点击反馈、随机动作、随机/条件/好感度对话。
- 好感系统：互动各有不同加值、等级与剧情门槛；状态自动保存在本机浏览器。
- 通讯页：短信收件箱、主动来信、玩家选项回复和对话记录。
- 「潮汐档案」完整剧情：场景探索、分支回复、结束结算与关系状态变化。
- 设置页：角色档案、进度与本地存档重置。

## 项目结构

assets/：原创 SVG 与静态资源
data/：角色、对话、消息、场景配置
docs/：设计、角色、架构、路线图和变更记录
src/app/：应用入口与导航
src/core/：存档、好感度与游戏状态
src/ui/：页面渲染、交互和角色舞台适配器

## 原创内容说明

当前角色为暂定方案「沈砚舟」，仅用于验证第一版玩法；角色经历、视觉稿、剧情和台词均为原创，后续将按角色设计流程继续打磨。本原型不使用《恋与深空》角色或美术素材。
