# 雾港来信

一款以碎片化陪伴、互动和剧情为核心的原创恋爱互动游戏原型。当前版本 **0.3.0 · 一盏留给你的灯**：动态立绘、分支相处、记忆问候、完整短信记录与剧情。项目使用原生 HTML、CSS、JavaScript 和 WebGL，无第三方运行时依赖。

## 技术选型

第一阶段采用 **Web（原生 ES Modules）+ WebGL 动态立绘 + CSS 界面**：

- 开发速度与 AI 协作：标准 Web 技术、模块边界清楚，修改和审阅成本低；当前无第三方运行时依赖。
- Windows 与移动端：直接在桌面浏览器运行，布局适配手机尺寸；未来可以按需要封装为 PWA 或移动端容器。
- UI 和 2D → 3D：先用角色立绘、CSS 动效和数据驱动视图验证交互。展示层以 CharacterStage 接口隔离；后续可用 Three.js 场景替换立绘舞台，而不重写关系、对话和剧情状态。
- GitHub 协作：静态文件可直接预览与审查，不需要大型二进制资源或特定编辑器。

Godot 4 是后续需要场景编辑器、骨骼动画、原生打包或大量实时 3D 内容时的候选方案；在当前以 UI 和陪伴链路验证为主的阶段，直接引擎化会增加启动成本。本选型并不把最终引擎永久锁定。

## 运行

在 Windows PowerShell 中进入仓库目录，运行 .\run-local.ps1，然后用浏览器打开 http://127.0.0.1:8000。按 Ctrl+C 停止。脚本只在本机回环地址提供项目静态文件，不需要安装 Python、Godot 或 npm 包。

## 当前可玩内容

- 动态角色舞台：独立眼睑表情、微笑过渡、局部呼吸、轻微头部/手部回应；实际画面坐标命中发梢、衣领和手部。支持近景、触碰提示和键盘替代按钮。
- 四段有结尾的分支相处：聊聊今天、理头发、牵手、整理衣领；逐字呈现、对话回看、随时退出。
- 相处记忆：记住心情和安静陪伴偏好，影响下次问候；相处手记持久保存。同一段相处每天仅首次加分。
- 一分钟安静陪伴、可选合成雨声；页面隐藏或离开陪伴页时计时暂停。
- 通讯页：保留所有来信和回复，显示输入中反馈；相处后的待发消息持久保存，刷新后继续送达。
- 「潮汐档案」：明确显示选择的回应、记录选择、一次性结算奖励；已完成故事可以完整重玩。
- 设置页：角色档案、进度与本地存档重置。

## 项目结构

assets/：角色立绘与静态资源
data/：角色、对话、消息、场景配置
docs/：设计、角色、架构、路线图和变更记录
src/app/：应用入口与导航
src/core/：存档、好感度与游戏状态
src/ui/：页面渲染、交互和角色舞台适配器

## 原创内容说明

当前男主显示名为「王彦祖」，稳定角色 ID 仍为 `male_01`；人物立绘采用项目创作过程中提供的原创角色参考图，角色经历、剧情和台词继续独立原创。本原型不使用《恋与深空》角色或美术素材。

静态网页通过 `data/app-version.js` 记录版本，发布前运行 `./scripts/update-cache-version.ps1 -Version 0.3.0`（替换为新版本），同步入口、全部模块和立绘 URL 的缓存参数。桌面侧栏与手机页脚均显示版本号。HTML 缓存最终由 Pages 的响应头决定，资源参数负责避开旧资源地址。

## 验证与实际边界

运行 `node scripts/check-interactions.mjs` 验证旧存档兼容、分支、奖励去重、消息、剧情重玩和缩放命中。浏览器中还需检查桌面/手机布局、动态表情与交互。

当前是基于原创立绘的局部形变与表情帧混合，**不是骨骼驱动的 3D 模型**；视角和姿势仍受原图限制。WebGL 不可用时保留原立绘和玩法。尊重系统减少动态效果偏好；没有真实语音、云端聊天或系统推送。素材来源与生成提示词见 `docs/ASSET_PROVENANCE.md`。

详见 docs/GAME_DESIGN.md 与 docs/TECH_ARCHITECTURE.md。
